Quickstart

Fund an account, call any x402 endpoint through the gateway, get billed per real call at your margin. That's the whole product.

Hard budget capsThe cap blocks before the paid call, not after. A dry balance fails loudly with 402.
Never double-chargedA timed-out call is never retried automatically. A possibly-paid call is never paid twice.

1
Install & get an API key

pip install tryx402

Then ask us (pilot phase) for a key like gw_… mapped to your funded account. Keep it secret; it IS your balance.

2
Call any endpoint

curl -X POST https://tryx402.app/v1/call \
  -H "X-API-Key: gw_YOUR_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "url": "https://stable-deepline.dev/api/email/work",
    "body": {"domain": "acme.com"},
    "price": 0.04
  }'

price is the expected upstream cost in USD. It feeds the budget check and your billing pre-auth. The response:

{
  "data":    { "...endpoint payload..." },
  "balance": "9.96 EUR",
  "account": "your-account"
}

3
Check balance

curl https://tryx402.app/v1/balance -H "X-API-Key: gw_YOUR_KEY"

How billing works

EventWhat happens
You fundCard payment via Stripe Checkout credits your account in its currency.
A call succeedsYour balance is debited: upstream USD cost × FX × margin, rounded up. Never undercharged.
Balance too lowThe call fails with 402 and nothing is spent upstream.
TimeoutNever retried automatically — a possibly-paid call is never double-charged.

Error codes

CodeMeaning
401Missing or unknown API key
402Budget cap or insufficient balance
502Upstream endpoint failed after payment attempt — contact support with the request id
